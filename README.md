## 👨‍💻 About Me

I am a Computer Applications undergraduate focused on building practical, reliable software and systems. My technical interests span cross-platform mobile engineering with Flutter, backend services in Java/Python, and self-hosted Linux network infrastructure.

- 📱 **Mobile Development**: Building responsive, clean cross-platform apps using **Flutter & Dart** (App Development Intern @ **CodeAlpha**).
- 🐧 **Linux & Self-Hosted Infrastructure**: Running a personal **Raspberry Pi homelab** with an encrypted mesh network via **Tailscale**, complemented by network-wide DNS sinkholing using **Pi-hole** and **AdGuard Home**.
- ⚙️ **Backend & Automation**: Developing structured REST APIs with **FastAPI** and **Java**, plus system-level automation scripts in **PowerShell** and **Bash**.
- 🏆 **Hackathons & Collaborative Work**: Contributed to **NCSpectra** for **Smart India Hackathon (SIH 2026)**, developing a deterministic mobile drug testing platform for the Narcotics Control Bureau.
